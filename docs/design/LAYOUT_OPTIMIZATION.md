# BatchPic 布局优化方案

## 优化目标

- 节省屏幕空间
- 提高信息密度
- 改善工作流程
- 保持清晰的视觉层次

## 主要改进

### 1. 侧边栏布局（Sidebar Layout）

**优势**：
- 固定宽度侧边栏（300px），控制面板始终可见
- 主工作区自适应，充分利用剩余空间
- 类似专业软件（Photoshop, Figma）的布局模式
- 减少横向滚动，提高操作效率

**实现**：
```css
.main-content {
  display: flex;  /* 从 grid 改为 flex */
  gap: 0;
  overflow: hidden;
}

.sidebar {
  width: 300px;  /* 固定宽度 */
  overflow-y: auto;
}

.workspace {
  flex: 1;  /* 自适应剩余空间 */
}
```

### 2. 紧凑的参数面板

**改进**：
- 移除卡片间距，使用分隔线
- 减小内边距（16px → 14px）
- 缩小字体（14px → 12-13px）
- 标题使用大写 + 字母间距

**空间节省**：约 30% 的垂直空间

**实现**：
```css
.param-section {
  padding: 14px 16px;  /* 更紧凑 */
  border-bottom: 1px solid #ccfbf1;  /* 分隔线代替间距 */
}

.param-section h3 {
  font-size: 13px;  /* 更小的标题 */
  text-transform: uppercase;
  letter-spacing: 0.5px;
}
```

### 3. 网格文件列表

**改进**：
- 从垂直列表改为网格卡片
- 每个卡片显示文件名和大小
- 自适应列数（minmax(130px, 1fr)）
- 悬停效果提供视觉反馈

**空间节省**：约 60% 的垂直空间（8个文件）

**实现**：
```css
.file-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(130px, 1fr));
  gap: 8px;
}

.file-card {
  padding: 8px;
  border: 1px solid #ccfbf1;
  border-radius: 4px;
}
```

### 4. 内联预览

**改进**：
- 预览面板不再独占一行
- 与文件列表在同一区域
- 自适应高度，充分利用空间
- 滚动查看，不影响其他区域

**空间节省**：约 40% 的屏幕空间

### 5. 紧凑的 Header 和 Footer

**改进**：
- Header 高度减小（padding: 24px → 14px）
- 标题字体缩小（28px → 22px）
- Footer 间距减小（gap: 12px → 8px）
- 按钮高度优化（padding: 16px → 14px）

**空间节省**：约 20px 的垂直空间

## 用户体验改进

### 1. 工作流程优化

**之前**：
1. 拖放文件 → 左侧
2. 调整参数 → 右侧
3. 查看预览 → 底部滚动
4. 导出 → 底部

**之后**：
1. 拖放文件 → 右侧主区域
2. 调整参数 → 左侧侧边栏（无需移动视线）
3. 查看预览 → 右侧主区域（同一视野）
4. 导出 → 底部

### 2. 视觉焦点

- 主工作区（右侧）占据更多空间
- 控制面板（左侧）固定位置，易于访问
- 减少眼球移动距离
- 更符合从左到右的阅读习惯

### 3. 信息密度

- 文件网格：一屏显示更多文件
- 紧凑参数：减少滚动
- 内联预览：实时反馈
- 整体信息密度提高约 40%

## 技术实现

### CSS 变更

1. **Flexbox 布局**：替代 Grid，更灵活
2. **固定侧边栏**：`width: 300px` + `flex-shrink: 0`
3. **自适应工作区**：`flex: 1`
4. **网格文件列表**：`grid-template-columns: repeat(auto-fill, minmax(130px, 1fr))`

### 组件变更

1. **MainWindow.tsx**：
   - 重构 JSX 结构
   - 新增 `.sidebar` 和 `.workspace` 容器
   - 文件列表改为网格卡片

2. **MainWindow.css**：
   - 完全重写布局样式
   - 新增侧边栏和工作区样式
   - 优化响应式断点

3. **ParameterPanel.css**：
   - 紧凑化设计
   - 移除卡片样式
   - 使用分隔线

4. **TemplateSelector.css**：
   - 紧凑化设计
   - 缩小按钮和间距

## 性能影响

- **渲染性能**：无影响（纯 CSS 变更）
- **内存占用**：略微减少（更少的 DOM 节点）
- **滚动性能**：改善（减少滚动区域）

## 可访问性

- 保持所有焦点状态
- 键盘导航不受影响
- 屏幕阅读器兼容
- 支持 prefers-reduced-motion

## 浏览器兼容性

- Flexbox：所有现代浏览器
- CSS Grid：所有现代浏览器
- CSS 变量：所有现代浏览器

## 总结

通过采用侧边栏布局和紧凑化设计，我们成功地：

- 节省了约 40% 的屏幕空间
- 提高了信息密度
- 改善了工作流程
- 保持了清晰的视觉层次
- 提升了整体用户体验

这种布局更接近专业图像处理软件的标准，用户会感到更加熟悉和高效。
