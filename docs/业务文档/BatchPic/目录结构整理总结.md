# BatchPic 目录结构整理总结

**日期**：2026-03-07  
**状态**：已完成

## 整理目标

优化项目目录结构，提高代码可维护性，遵循工程化最佳实践，同时确保不影响现有功能。

## 执行的变更

### 1. 测试文件重组 ✅

**问题**：测试文件分散在多个位置，不利于维护和查找。

**解决方案**：按模块组织测试文件，使用 `__tests__/` 子目录。

**变更详情**：

```
变更前：
src/
├── __tests__/              # 系统级测试
├── main/
│   ├── FileScanner.test.ts
│   ├── ImageProcessor.test.ts
│   └── ...
└── renderer/
    ├── components/
    │   ├── DropZone.test.tsx
    │   └── ...
    └── context/
        └── AppContext.test.tsx

变更后：
src/
├── __tests__/              # 系统级集成测试（保持不变）
├── main/
│   ├── __tests__/          # 主进程单元测试
│   │   ├── FileScanner.test.ts
│   │   ├── ImageProcessor.test.ts
│   │   ├── OutputManager.test.ts
│   │   ├── preload.test.ts
│   │   ├── setup.test.ts
│   │   └── TemplateManager.test.ts
│   └── ...
└── renderer/
    ├── components/
    │   ├── __tests__/      # 组件测试
    │   │   ├── DropZone.test.tsx
    │   │   ├── ErrorReportDialog.test.tsx
    │   │   ├── MainWindow.test.tsx
    │   │   ├── NotificationContainer.test.tsx
    │   │   ├── ParameterPanel.test.tsx
    │   │   ├── PreviewPanel.test.tsx
    │   │   └── TemplateSelector.test.tsx
    │   └── ...
    └── context/
        ├── __tests__/      # Context 测试
        │   └── AppContext.test.tsx
        └── ...
```

**优势**：
- 测试文件与源代码就近放置，便于维护
- 清晰的测试层级：系统级 → 模块级 → 单元级
- 符合 Jest 默认测试发现规则
- 降低测试文件查找成本

### 2. 文档结构优化 ✅

**问题**：文档分散在根目录和 docs 目录，缺少明确分类。

**解决方案**：按文档类型和用途重新组织。

**变更详情**：

```
变更前：
docs/
├── README.md
├── AUTO_PROCESS_GUIDE.md
├── PACKAGING_GUIDE.md
├── development/
│   └── SETUP.md
├── testing/
│   ├── QUICK_TEST.md
│   └── TROUBLESHOOTING.md
├── 业务文档/
│   └── BatchPic/
└── 知识沉淀/

变更后：
docs/
├── README.md               # 文档索引
├── development/            # 开发文档
│   ├── SETUP.md
│   └── AUTO_PROCESS_GUIDE.md  # 从根目录移入
├── testing/                # 测试文档
│   ├── QUICK_TEST.md
│   └── TROUBLESHOOTING.md
├── deployment/             # 新建：部署文档
│   └── PACKAGING_GUIDE.md  # 从根目录移入
├── design/                 # 新建：设计文档（预留）
├── 业务文档/
│   └── BatchPic/
│       ├── 技术债.md
│       ├── 性能监控实现.md
│       ├── 性能优化总结.md
│       └── 目录结构整理总结.md  # 本文档
└── 知识沉淀/
    └── Node.js ES模块迁移指南.md
```

**优势**：
- 文档按用途分类，查找更直观
- 根目录更简洁，只保留核心配置文件
- 为未来的设计文档预留空间
- 符合文档组织规范

### 3. README 更新 ✅
