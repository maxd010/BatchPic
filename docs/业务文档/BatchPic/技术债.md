## 技术债：Preload 脚本 CommonJS 配置

- **引入时间**：2026-03-07
- **原因**：Electron preload 脚本不支持 ES Module,必须使用 CommonJS 格式
- **影响范围**：
  - 构建配置复杂度增加
  - 需要维护两套 TypeScript 配置文件 (`tsconfig.main.json` 和 `tsconfig.preload.json`)
  - 构建脚本需要执行两次编译
  - preload.ts 无法使用 ES Module 特性
- **替换方案**：
  - 等待 Electron 官方支持 preload 脚本使用 ES Module
  - 关注 Electron 更新日志和 Issue 讨论
  - 相关 Issue: https://github.com/electron/electron/issues/21457
- **优先级**：低
- **预计解决时间**：待 Electron 官方支持 (预计 2026-Q3 或更晚)

### 当前实现

**文件结构**:
```
tsconfig.main.json      # 主进程 ES Module 配置
tsconfig.preload.json   # Preload CommonJS 配置
```

**构建命令**:
```bash
npm run build:main
# 实际执行: tsc -p tsconfig.main.json && tsc -p tsconfig.preload.json
```

### 为什么不能统一为 ES Module

Electron 的安全架构要求:
1. Preload 脚本在渲染进程加载前执行
2. 需要同步加载,不能使用异步的 ES Module
3. 必须在沙箱环境中运行,限制了模块系统
