# BatchPic

图片交付准备工具 - 快速批量处理图片以满足交付要求

## 技术栈

- **Electron** - 跨平台桌面应用框架
- **React** - UI 框架
- **TypeScript** - 类型安全
- **Sharp** - 高性能图片处理（基于 libvips）
- **Jest** - 测试框架
- **fast-check** - 基于属性的测试

## 功能特性

### 核心功能
- **拖拽即处理** - 拖放图片后自动处理，无需点击按钮
- **实时进度跟踪** - 按图片显示处理状态和进度
- **批量调整大小** - 保持宽高比的智能缩放
- **批量压缩** - 高效的图片压缩（默认质量 70%）
- **格式转换** - 支持 JPG、PNG、WebP 格式互转
- **处理模板** - 保存和重用常用处理参数
- **单窗口界面** - 简洁直观的用户体验
- **本地处理** - 所有处理在本地完成，保护隐私

### 自动处理功能（新）
- **自动触发** - 拖拽图片后立即开始处理
- **预设参数** - 使用优化的默认参数（质量 70%，保持原始尺寸和格式）
- **进度面板** - 实时显示每张图片的处理状态
- **成功/失败指示** - 清晰的视觉反馈
- **文件大小对比** - 显示压缩前后的文件大小和压缩比例
- **错误报告** - 处理失败时自动显示详细错误信息
- **可选开关** - 可以关闭自动处理，改为手动触发

## 使用指南

### 基本使用

1. **启动应用**
   ```bash
   npm run dev
   ```

2. **拖拽图片**
   - 将图片文件或文件夹拖放到应用窗口
   - 系统会自动扫描所有支持的图片格式（JPG、PNG、WebP）

3. **自动处理**
   - 扫描完成后，图片会自动开始处理
   - 进度面板会实时显示每张图片的处理状态
   - 处理完成后会显示通知

4. **查看结果**
   - 处理后的图片保存在用户主目录的 `BatchPic_Output` 文件夹
   - 每次处理会创建带时间戳的子文件夹
   - 保持原始的文件名和目录结构

### 自动处理功能

#### 启用/禁用自动处理

应用默认启用自动处理功能。如果您希望手动控制处理时机：

1. 在主界面找到"自动处理"开关
2. 关闭开关后，拖拽图片只会扫描文件
3. 需要手动点击"开始导出图片"按钮来处理

#### 进度面板说明

进度面板会显示每张图片的详细信息：

- **⏱️ 等待中（Pending）** - 图片已扫描，等待处理
- **⚙️ 处理中（Processing）** - 图片正在处理
- **✅ 成功（Success）** - 处理完成，显示文件大小对比和压缩比例
- **❌ 失败（Failed）** - 处理失败，显示错误原因

#### 默认处理参数

自动处理使用以下优化的默认参数：

- **质量**：70%（在文件大小和图片质量间取得平衡）
- **尺寸**：保持原始尺寸
- **格式**：保持原始格式
- **并发处理**：根据 CPU 核心数自动调整

#### 错误处理

如果处理过程中出现错误：

1. 失败的图片会在进度面板中标记为红色
2. 显示具体的错误信息
3. 其他图片会继续处理，不受影响
4. 处理完成后会自动显示错误报告对话框

### 已知限制

- **超大图片**：超过 1 亿像素（约 8000x8000）的图片会自动缩小到安全尺寸
- **并发限制**：并发处理数量限制为 CPU 核心数，避免内存溢出
- **文件格式**：仅支持 JPG、PNG、WebP 格式
- **输出位置**：输出目录固定在用户主目录（未来版本将支持自定义）

### 性能指标

- **单张图片处理时间**：< 500ms（1920x1080, 质量 70%）
- **100 张图片批量处理**：< 30s（4 核 CPU）
- **内存占用**：< 500MB（处理 100 张图片）
